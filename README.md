## 🎯 **Objetivo**
Criar um site completo para uma ONG fictícia, permitindo:
- Visualizar projetos e ações sociais
- Cadastrar voluntários e apoiadores
- Garantir acessibilidade (WCAG 2.1 AA)
- Implementar responsividade para diferentes dispositivos
- Integrar um modo escuro acessível e moderno

---

## 🧩 **Estrutura do Projeto**
O site é dividido em três páginas principais:
1. **Início (`index.html`)** — apresenta a ONG, missão, visão e valores.
2. **Projetos (`projetos.html`)** — exibe os projetos sociais desenvolvidos.
3. **Cadastro (`cadastro.html`)** — formulário para novos voluntários/apoiadores.

---

## 🖥️ **Tecnologias Utilizadas**
- **HTML5** — estrutura semântica e acessível  
- **CSS3** — design system, grid, flexbox e modo escuro  
- **JavaScript (ES6)** — SPA, validação de formulários e interatividade  
- **Git & GitHub** — versionamento e deploy  
- **WCAG 2.1 AA** — boas práticas de acessibilidade  

---

## ⚙️ **Funcionalidades**
✅ Navegação SPA (Single Page Application)  
✅ Modo escuro com armazenamento de preferência  
✅ Formulário com validação de dados  
✅ Layout totalmente responsivo (5 breakpoints)  
✅ Estrutura modular de CSS e JS  
✅ Acessibilidade com `aria-label`, `skip-link` e foco visível  

---

## 🎨 **Design System**
| Tipo | Variáveis |
|------|------------|
| 🎨 Cores | 8 tons (primárias, secundárias e neutras) |
| 🔤 Tipografia | Poppins (5 tamanhos de fonte) |
| 📏 Espaçamento | 8px, 16px, 24px, 32px, 48px, 64px |
| 🧱 Layout | Grid 12 colunas + Flexbox |
| 🌗 Tema | Claro e escuro com contraste AA |

---

## 🌗 **Acessibilidade**
- Navegação completa por teclado (`Tab`, `Enter`)  
- Alto contraste entre texto e fundo  
- Suporte para leitores de tela (`aria-label`, `role`)  
- Skip link para pular direto ao conteúdo  
- Validação visual de campos obrigatórios
